Open a merchant's trades by right-clicking them, like any villager. The window is titled with their
profession (or `Name (Profession)` if you gave them a name tag).

```item
id: emerald
label: One emerald per miniblock
```

## How trades work

* Every trade is **1 emerald for 1 miniblock**.
* All trades are available from the start. There are no levels to unlock.
* Trades practically never run out (each one can be used 99,999 times), so there is no need to restock.
* Prices do not go up when you buy a lot.

## Counting your purchases

Each miniblock you buy adds to the **Traded with Miniblock Merchants** statistic, which you can see in the
Statistics screen. It also counts towards the [trading advancements](../05-advancements.md).

> [!TIP]
> A single stack of emeralds buys a whole stack of miniblocks. Bring plenty of emeralds before you set off to
> decorate.

See [what each profession sells](../03-professions/index.md).
