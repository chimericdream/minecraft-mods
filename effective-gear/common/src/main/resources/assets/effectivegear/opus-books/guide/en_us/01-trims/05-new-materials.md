Effective Gear adds nine new armor trim materials. Use them in a smithing table exactly like vanilla trim
materials: put in the armor piece, a trim template, and the material.

| Item | Material name |
|:-----|:--------------|
| ![Blaze powder](item:minecraft:blaze_powder) Blaze powder | Blaze Powder |
| ![Echo shard](item:minecraft:echo_shard) Echo shard | Echo Shard |
| ![Enchanted golden apple](item:minecraft:enchanted_golden_apple) Enchanted golden apple | Enchanted Golden Apple |
| ![Ender pearl](item:minecraft:ender_pearl) Ender pearl | Ender Pearl |
| ![Honeycomb](item:minecraft:honeycomb) Honeycomb | Honeycomb |
| ![Nether star](item:minecraft:nether_star) Nether star | Nether Star |
| ![Prismarine shard](item:minecraft:prismarine_shard) Prismarine shard | Prismarine Shard |
| ![Slimeball](item:minecraft:slime_ball) Slimeball | Slimeball |
| ![Turtle scute](item:minecraft:turtle_scute) Turtle scute | Turtle Scute |

Each one has a [full-set bonus](02-material-bonuses.md), like the vanilla materials.
