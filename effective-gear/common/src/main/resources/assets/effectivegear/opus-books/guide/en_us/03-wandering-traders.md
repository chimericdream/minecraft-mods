Wandering traders now have a 20% chance of selling a random smithing template. Each offer can be used once.

The cost matches the recipe for duplicating that template: **7 diamonds** plus one of the block normally used to
copy it.

| Template | Extra item |
|:---------|:-----------|
| Bolt | Copper block |
| Coast | Cobblestone |
| Dune | Sandstone |
| Eye | End stone |
| Flow | Breeze rod |
| Host | Terracotta |
| Netherite upgrade | Netherrack |
| Raiser | Terracotta |
| Rib | Netherrack |
| Sentry | Cobblestone |
| Shaper | Terracotta |
| Silence | Cobbled deepslate |
| Snout | Blackstone |
| Spire | Purpur block |
| Tide | Prismarine |
| Vex | Cobblestone |
| Ward | Cobbled deepslate |
| Wayfinder | Terracotta |
| Wild | Mossy cobblestone |

See [pattern bonuses](01-trims/03-pattern-bonuses.md) for what each pattern does.
