title: Houdini Block
---
Welcome to the Houdini Block guide. Normally, placing or breaking a block nudges the blocks around it, which makes
sand fall, water flow, and redstone re-check itself. The Houdini Block can skip that nudge, so it can come and go
without disturbing anything nearby.

```item
houdiniblock:houdini_block
```

## Where to start

* [The block](01-the-block.md): how to craft it and switch its mode.
* [The four modes](02-modes.md): what each mode does.
* [Replace mode](03-replace-mode.md): swap blocks in a finished build without side effects.
* [Good to know](04-good-to-know.md): drops, water, and limits.
