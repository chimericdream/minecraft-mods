Replace mode is for changing a block that is already part of a build, such as one inside a powered redstone line or
under floating sand, without disturbing what is around it.

## Putting a Houdini Block in

With the block set to **Replace block**, right-click an existing block. That block is removed, and anything it
would normally drop is dropped, then the Houdini Block takes its place with no update to its neighbors.

Blocks that cannot be broken, such as bedrock, cannot be replaced this way.

## Swapping a block in

Now hold any other block and right-click the Houdini Block. Your block takes its place, again with no update, and
the Houdini Block drops back as an item so you can use it again. In creative mode nothing is used up and the
Houdini Block does not drop.

## Putting it together

1. Set a Houdini Block to Replace block and place it where you want to make a change.
2. Rebuild or adjust the area around it.
3. Right-click it with the block you want there instead.

> [!TIP]
> Breaking a placed Replace block also sends no updates.
