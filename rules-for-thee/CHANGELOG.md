### Unreleased changes

#### New Features

* Added Rules for Thee. Give single players, or named profiles of players, their own value for the game rules that apply to that player. See the README for the supported rules and the `/rulesforthee` commands.
* Optional compatibility with *Your Items Are Safe*. Its death chest and armor stand use the `keepInventory` value of each player. Nothing changes if that mod is not installed.
