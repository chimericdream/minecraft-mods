### Unreleased changes

#### New Features

* Added Rules for Thee: give individual players, or named profiles of players, their own value for the game rules that are about that player. See the README for the list of supported rules and the `/rulesforthee` commands.
* Optional compatibility with *Your Items Are Safe*: its death chest and armor stand now follow each player's own `keepInventory` value. Nothing changes if the mod isn't installed.
* Added `pvp` as a per-player rule. A player with PVP off can't hurt other players and other players can't hurt them.
