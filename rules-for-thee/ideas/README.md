# Rules for Thee — Ideas

Feature ideas for this mod, from first thought to ready to build. The process is described in
[`docs/FEATURE-WORK.md`](../../docs/FEATURE-WORK.md).

## Identity

> Per-player game rules for shared servers: an operator can give individual
> players (or groups of players) their own value for a game rule wherever the rule is about *that player*,
> while everyone else keeps the world's setting. The motivating case is a hard-difficulty, no-keep-inventory
> server where only the kids keep their inventory on death. Not a difficulty-scaling mod, not a permissions
> mod, and not a replacement for game rules. If a rule is inherently global (world time, weather, mob
> spawning caps), it stays global.

## Active ideas

- [Per-player game rule overrides](core/per-player-rule-overrides.md) — The core mechanism: a named
  profile of rule overrides that can be assigned to players, starting with `keepInventory`.
- [Supported rules](core/supported-rules.md) — Which game rules can be overridden per player, in what
  order, and how each is hooked.
- [Grave-mod compatibility](core/grave-mod-compatibility.md) — Research: making per-player
  `keepInventory` work with *Your Items Are Safe* and similar mods.
