Direction and decisions
The sentence is the layout; seed 1550349443, dealt with --keep palette.
On this page, chimericdream's useful and odd creations become the specimens
inside a maker's catalogue sentence. The opening is Useful mods. Odd ideas.,
with actual repository artwork between the two halves. The live thing is a
small client-side search across all 34 mods, with an ordinary linked catalogue
as its no-JavaScript fallback.

Redraws: Barlow Condensed/Barlow was rejected for its industrial road-sign voice,
which conflicts with the fantasy brief. The redraw yielded Hanken Grotesk,
used for body text; Young Serif supplies the brief's storybook display voice.
The prompt-tool showcase was redrawn as unequal panels for the four real mods.
The original 5-14-row list was redrawn as a catalogue menu because there are
30 other mods. The final direction JSON records the three supported redraws.
The attempted type=<id> syntax was unsupported and made no change.

Brand defaults: the path-based dragon mark, a Young Serif wordmark, snow-lilac
paper in light mode, ink violet in dark mode, and crimson/rose actions.
Dark and light follow the OS. Manual light/dark/system choice persists locally.
No new infrastructure, runtime framework, library or package dependency.
No scripts/site/local files changed; THEME_CSS remains re-exported from layout.ts.

Changes
Four unequal feature entries, then a dense unboxed directory with versions,
loaders, Minecraft versions and status. Search includes the featured four.
Mod headers include repository metadata and actual CurseForge project-ID links.
Minekea's existing jars screenshot supplies a product preview.
Guide trees retain the existing hierarchy, with a native collapsible container
on phones. Reading measure, callouts, tables, recipes and code have their own
styles. Roadmap filters use 44px buttons with aria-pressed; table sorting also
responds to Enter/Space and announces aria-sort. Its value rating now reads
as a number out of three, using the same underlying data.
Native scroll-driven specimen swaps, brief picture/text/list arrivals and
sticky feature artwork supply motion. Reduced motion skips these enhancements.
