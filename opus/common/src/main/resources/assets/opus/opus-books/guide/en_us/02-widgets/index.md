Widgets are fenced code blocks whose label is the widget name. The body is [YAML](https://yaml.org).

If a widget has a mistake, the page shows the error in its place and the validator lists it, instead of the
book failing to open.

* [Recipes](01-recipes.md) - crafting, smelting, stonecutting and more, drawn like the real screens
* [Items and mobs](02-items-and-entities.md)

Every widget is also shown in the [kitchen sink](../99-appendices/kitchen-sink.md).
