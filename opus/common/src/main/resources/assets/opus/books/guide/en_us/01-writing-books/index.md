A book is written once and read everywhere: the same files work in a resource pack, a mod's assets, or a
folder you are editing right now.

Start with the [folder layout](01-folder-layout.md), then learn what goes in the
[frontmatter](02-frontmatter.md), which [Markdown](03-markdown.md) is supported, and how
[links](04-links.md) work. For recipes, items and mobs, see the [widgets](../02-widgets/index.md).
