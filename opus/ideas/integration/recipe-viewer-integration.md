# Recipe viewer integration (EMI/JEI/REI)

> Source: initial design discussion, 2026-10-06 · Effort **L** · Value ★★
> Status: **Exploring**

## Description

Clicking a recipe widget opens the recipe in whichever viewer is installed, and the viewer's "uses/recipes" pages can link back to a book page about the item.

**Out of scope:** hard-depending on any recipe viewer.

**Dependencies:** Each viewer's API, optional dependencies on both loaders.
**Verification:** Manual pass with each viewer installed.
