# Lava-logging

> Source: [`brainstorms/2026-08-30-legacy/`](../brainstorms/2026-08-30-legacy/potential-features.md) · Status: **Shipped** in 26.2-1.0.0

## Description

"Lava-log" any non-flammable block that can currently be waterlogged. Implemented for slabs, stairs, walls,
fences, iron bars/glass panes, trapdoors, ladders, and chains, via bucket interaction only (not on placement
into lava). See `CHANGELOG.md`.
