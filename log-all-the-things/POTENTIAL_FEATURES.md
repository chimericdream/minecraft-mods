# Potential Features — Log All the Things!

Brainstormed, thematically appropriate feature ideas. Nothing here is committed or implemented; these are starting points for future planning.

The mod's identity: generalize vanilla's waterlogging mechanic to other fluids/materials.

## From the idea backlog (2026-08-13)

* **Lava** — "lava-log" any non-flammable block that can currently be waterlogged.
* **Carpet** — "carpet-log" stairs, slabs, etc.
* **Glass panes** — "window-log" a stairs or slab block to make a window.
