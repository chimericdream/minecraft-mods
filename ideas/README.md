# Repo-level ideas

Ideas that span the whole repo or sit outside any one mod. Feature ideas for a specific mod live in that
mod's own `ideas/` folder; the process is described in [`docs/FEATURE-WORK.md`](../docs/FEATURE-WORK.md).

## Active ideas

- [Getting more eyes on the mods](marketing-ideas.md) — Ranked ways to get more people using the mods,
  by joy per hour of effort. Builds on the (implemented) CurseForge publishing work.
- [Compatibility repro scaffold](compat-repro-scaffold.md) — Point a local command at a GitHub issue, and it reads it,
  downloads the other mods, and sets up a Docker environment to reproduce the bug. It then stops. The
  user decides whether to run it. Exploring.
