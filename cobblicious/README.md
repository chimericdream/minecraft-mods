# Cobblicious (Fabric/NeoForge)

![Version: 1.0.0](https://img.shields.io/badge/version-1.0.0-blueviolet?style=flat-square) ![Modloader: Fabric](https://img.shields.io/badge/modloader-Fabric-1976d2?style=flat-square) ![Modloader: NeoForge](https://img.shields.io/badge/modloader-NeoForge-1976d2?style=flat-square) ![Client: required](https://img.shields.io/badge/client-required-4caf50?style=flat-square) ![Server: required](https://img.shields.io/badge/server-required-4caf50?style=flat-square)

_Block sets beyond vanilla: mossy, crimson, and warped stone variants, new brick types, and the matching stairs, slabs, and walls._

## Introduction

Cobblicious adds block sets that Mojang never made. They fit with vanilla's stone and building blocks.

### Minecraft Versions

* 26.2: Supported

### Dependencies

* Required: Architectury API, ChimericLib 6.7.0 or newer, and YACL.
* Optional: Forwarding Address 1.0.0 or newer. When loaded, existing worlds convert the old Minekea versions of these blocks and items to the Cobblicious ones.

### Current Features

* Basalt Bricks, Chiseled Basalt Bricks, Cracked Basalt Bricks, Crimson Basalt Bricks, Mossy Basalt Bricks, Warped Basalt Bricks, and Warped Nether Bricks
* Stairs, slabs, and walls for each of these blocks, except Chiseled Basalt Bricks
* Mossy, crimson, and warped versions of vanilla stone blocks, each with stairs, a slab, and a wall. Craft each one from the vanilla block and a vine: Vine for mossy, Weeping Vines for crimson, Twisting Vines for warped.
  * Mossy: Andesite, Bricks, Cinnabar Bricks, Tuff Bricks, Cracked Stone Bricks, Cobbled Deepslate, Deepslate Bricks, Cracked Deepslate Bricks, Deepslate Tiles, Cracked Deepslate Tiles
  * Crimson and Warped: Blackstone, Polished Blackstone Bricks, Cracked Polished Blackstone Bricks, Cracked Nether Bricks
* Warped Wart. Plant it on soul sand. It is an ingredient of Warped Nether Bricks.
