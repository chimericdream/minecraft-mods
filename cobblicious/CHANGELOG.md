### Unreleased changes

### 26.2 - 1.0.0

#### New Features

* Added these blocks:
  * Basalt Bricks
  * Chiseled Basalt Bricks
  * Cracked Basalt Bricks
  * Crimson Basalt Bricks
  * Mossy Basalt Bricks
  * Warped Basalt Bricks
  * Warped Nether Bricks
* Added stairs, slabs, and walls for each of these blocks, except Chiseled Basalt Bricks.
* Added mossy, crimson, and warped versions of vanilla stone blocks. Each has stairs, a slab, and a wall. Craft each one from the vanilla block and a vine: Vine for mossy, Weeping Vines for crimson, Twisting Vines for warped.
  * Mossy: Andesite, Bricks, Cinnabar Bricks, Tuff Bricks, Cracked Stone Bricks, Cobbled Deepslate, Deepslate Bricks, Cracked Deepslate Bricks, Deepslate Tiles, Cracked Deepslate Tiles
  * Crimson and Warped: Blackstone, Polished Blackstone Bricks, Cracked Polished Blackstone Bricks, Cracked Nether Bricks
* Added Warped Wart. Plant it on soul sand. It is an ingredient of Warped Nether Bricks.
* When Forwarding Address is loaded, existing worlds convert the old Minekea versions of these blocks and items to the Cobblicious ones. Forwarding Address is an optional dependency.
