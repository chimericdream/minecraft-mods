# Cobblicious — Ideas

Feature ideas for this mod, from first thought to ready to build. The process is described in
[`docs/FEATURE-WORK.md`](../../docs/FEATURE-WORK.md).

## Identity

> **The extended block sets.** Cobblicious is the addon to [But What About...?](../../but-what-about/ideas/README.md)
> for block families that go beyond finishing Mojang's own: mossy variants of stones that don't have one,
> new kinds of moss (crimson, warped, sculk, and so on), and the stairs, slabs, walls, and cracked,
> chiseled, pillar, or smooth variants that go with them. Ideas should look like they belong with
> vanilla's stone and building blocks, even where Mojang never made them.

### Name and boundaries

- **"Cobblicious" is a working name** and will probably change to something that shows the link to
  But What About...?. The folder keeps this name until then.
- **But What About...?** completes vanilla's own block families. This mod invents the extensions.
  It builds on that mod and requires it.
- **Minekea** has some of these blocks today. As with But What About...?, they'll move here over time,
  and Minekea is being pared down over the next few major versions. The migration plan is in
  [But What About...?'s identity section](../../but-what-about/ideas/README.md#boundary-with-minekea):
  the new mod adds the block, Minekea keeps the old one registered and converts it on first tick, and
  Minekea gains a required dependency on the new mod.
