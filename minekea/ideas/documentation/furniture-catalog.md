# Furniture catalog

> Shortlist #23 · Tier 2 — Solid mid-size features · Effort **M** · Value ★ · Votes — · My vote **Yes, but Opus**
> Status: **Exploring**

## Description

A Patchouli "showroom catalog" that lists every Minekea block with its recipe. **Recommendation:** only if
you want an optional Patchouli dependency, and generate it with datagen from the block list so it stays
accurate. Low value until the block count is stable, since the mod is being pared down.

## Decisions

- Vote note: **Yes, but Opus.** The catalog will be built with your Opus mod, not Patchouli. The Description above still talks about Patchouli and its optional dependency; treat that part as superseded.
- Generating the catalog from the block list (datagen) still applies, so it stays accurate.
