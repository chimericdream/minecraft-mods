Use [warped wart](../06-crops-and-fluids/01-warped-wart.md) to make warped versions of nether bricks. They come with a
slab, stairs, vertical versions and a wall like other brick blocks.

```recipe
pattern: ["AB", "BA"]
key:
  A: minekea:crops/warped_wart
  B: nether_brick
result: minekea:building/general/warped_nether_bricks
```
