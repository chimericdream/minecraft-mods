Some blocks can be dyed any of Minecraft's 16 colours: smooth stone, stone, stone bricks, cobblestone, bricks, mud bricks,
oak planks, calcite, bone block, and the prismarine family. Surround the block with the dye of your choice.

```recipe
pattern: ["###", "#D#", "###"]
key:
  "#": smooth_stone
  D: blue_dye
result: minekea:building/dyed/smooth_stone/blue
count: 8
```

All dyed blocks follow the same pattern, but not every block can be dyed.

> [!NOTE]
> The [block painter](../05-tools/03-block-painter.md) recolours vanilla coloured blocks such as wool and concrete. It does
> not repaint these dyed blocks.
