Beams are thin posts that look a bit like fence posts or walls. By default a beam connects to every block next to it.
There are beams for well over a hundred materials, and they all use the same recipe.

```recipe
pattern: ["# #", "# #", "# #"]
key:
  "#": cobblestone
result: minekea:building/beams/cobblestone
count: 6
```

## Choosing connections

Right-click a beam with a [wrench](../05-tools/01-wrench.md) to switch the connection on that arm on or off. Each of the
six sides can be set separately, so you can build almost any shape.

Beams can be waterlogged.
