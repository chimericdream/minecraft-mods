_Ultraviolet light for Minecraft: UV-emitting blocks, gear to see them, and the effects they have_

## Introduction

Blacklight adds ultraviolet light as a second kind of light. UV is invisible to the naked eye, but it has effects
of its own, and special gear reveals it. The mod is planned and not built yet. The first ideas are:

* a block that emits UV light and keeps mobs from spawning without lighting up the area
* a way to imbue other blocks with UV light
* a wearable that lets you see UV-lit blocks

### Minecraft Versions

* 26.2: Supported

### Current Features

None yet. The mod is a placeholder while the first features are built.
