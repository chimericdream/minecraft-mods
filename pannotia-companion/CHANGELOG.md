### Unreleased changes

#### Bug Fixes

* `/pc fixheads` now also repairs Brown, White, Black, Gold, and Salt and Pepper rabbit heads that use an old texture.

### 26.2 - 1.1.0

#### Bug Fixes

* Wandering trader heads now show their own name, not "pannotia's Head".
* Stonecutter mini blocks now stack with wandering trader mini blocks.

#### New Features

* Added `/pc fixheads`. It repairs heads in your inventory that lost their name or do not stack with new heads.

### 26.2 - 1.0.0

* Added `/pc home`, `/pc homes`, `/pc spawn` and `/pc back` commands, replacing the Homes, Spawn and Back datapacks.
* Wandering traders now also sell mini block and streamer heads.
* Added mob head, husk sand, Ender Dragon, and shulker shell (Looting) drops as additions to existing loot.
* Ancient debris now drops netherite scrap unless mined with Silk Touch.
* Added the pack's custom recipes and item tags. They all live in this mod's own namespace (none replace vanilla recipes), so a mod like Polymorph is needed to pick between recipes with the same ingredients.
* Fabric only: the NeoForge version was removed.
* Copper, emerald, quartz, amethyst and other storage blocks can now be used as beacon bases.
* Added the World of Pannotia guide book (an Opus book). Players receive it on first join, and it can be crafted with a book and a compass. Opus is now required.
