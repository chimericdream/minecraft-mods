# Spawn

Part of the Pannotia Companion mod. `/pc spawn` teleports you to the Overworld's world spawn from any dimension, free and with no cooldown by default.

## How to use

| Command | What it does |
|---|---|
| `/pc spawn` | Teleport to the world spawn |

Use `/pc back` ([Back](back.md)) to return to where you were.

## What it changes

- You land at a safe spot at the spawn point. Your previous position is saved for Back.
- The server's config can add a stand-still delay and a cooldown. Both default to none, and cooldowns reset when the server restarts.
