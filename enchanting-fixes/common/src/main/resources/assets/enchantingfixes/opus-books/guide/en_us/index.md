---
title: Enchanting Fixes
---
This mod fixes enchanted books that do not stack. It also lets you change the maximum level of each
enchantment.

## Where to start

* [Book repair](01-book-repair.md): make enchanted books stack again.
* [Maximum levels](02-max-levels.md): set the maximum level of each enchantment.
* [Scaling Enchantments](03-scaling-enchantments.md): an optional data pack for high-level enchantments.
* [Settings](04-settings.md): all the settings and where to change them.
* [Advancements](05-advancements.md): goals for very high levels.
* [Compatible enchantments](06-compatibility.md): put more enchantments on the same item.
* [Advanced Silk Touch](07-silk-touch.md): an optional data pack with an enchantment that collects spawners and bedrock.

## Get a new guide

Craft a book and an enchanted book. Any enchanted book works. You can also use `/opus give enchantingfixes:guide`.

```recipe
type: crafting_shapeless
ingredients: [book, enchanted_book]
result: opus:book
```

> [!WARNING]
> The recipe uses the enchanted book. Use a book that you do not need.
