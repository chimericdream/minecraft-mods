An anvil or a grindstone can add a repair cost to an enchanted book. Two books with the same enchantments but a
different repair cost do not stack.

## How to use

Type `/enchfix fixbooks`. The command removes the repair cost from the enchanted books in your inventory. Then
books with the same enchantments stack again. All players can use the command.

## Books that do not change

The command changes only plain books. A plain book stores known enchantments and has no other changes, such as a
name, lore, or custom data. Mods and data packs can use enchanted books for other purposes, so the command does not
change those books.
