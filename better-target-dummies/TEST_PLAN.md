# Better Target Dummies test plan

1. **Guide book**
   * Craft a book and a target block: you get the Better Target Dummies Guide. `/opus give bettertargetdummies:guide` gives the same book.
   * Open it: all four pages open, the recipes show on crafting panels, and the links between pages work.
   * Without Opus installed, the game starts normally, the mod works, and there is no guide recipe (nothing logs a recipe parse error about `opus:book`).
   * With Opus older than 1.2.0 installed, the game refuses to start.
