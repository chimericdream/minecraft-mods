The Diamond Hopper Item Filter works exactly like the standard [Hopper Item Filter](01-hopper-item-filter.md), but gives
you ten slots to define blocks or items instead of five.

Upgrade a standard filter with a diamond:

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:hopper_item_filter, diamond]
result: hopperxtreme:diamond_hopper_item_filter
```

> [!WARNING] Upgrading resets the filter
> The upgraded filter starts over in include mode with no items set, so it is cheapest to upgrade a filter
> before you fill it in.
