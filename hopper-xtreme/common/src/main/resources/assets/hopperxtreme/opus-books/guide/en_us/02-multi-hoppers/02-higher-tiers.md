Combine four hoppers of the same tier to build any of these. The Golden and Diamond ones can also be made by upgrading
the Multi-Hopper below them. Any multi-hopper can be broken back into four hoppers of its tier.

## Golden Multi-Hopper

**Cooldown:** 4 game ticks (5 items per second)

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:multi_hopper, gold_ingot, gold_ingot, gold_ingot, gold_ingot]
result: hopperxtreme:golden_multi_hopper
```

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:golden_hopper, hopperxtreme:golden_hopper, hopperxtreme:golden_hopper, hopperxtreme:golden_hopper]
result: hopperxtreme:golden_multi_hopper
```

## Diamond Multi-Hopper

**Cooldown:** 2 game ticks (10 items per second)

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:golden_multi_hopper, diamond, diamond, diamond, diamond]
result: hopperxtreme:diamond_multi_hopper
```

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:diamond_hopper, hopperxtreme:diamond_hopper, hopperxtreme:diamond_hopper, hopperxtreme:diamond_hopper]
result: hopperxtreme:diamond_multi_hopper
```

## Netherite Multi-Hopper

**Cooldown:** 1 game tick (20 items per second)

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:netherite_hopper, hopperxtreme:netherite_hopper, hopperxtreme:netherite_hopper, hopperxtreme:netherite_hopper]

```

## Nether Star Multi-Hopper

**Cooldown:** 1 game tick (up to 320 items per second)

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:nether_star_hopper, hopperxtreme:nether_star_hopper, hopperxtreme:nether_star_hopper, hopperxtreme:nether_star_hopper]
result: hopperxtreme:nether_star_multi_hopper
```

## Breaking one down

Put any multi-hopper alone in the crafting grid to get four hoppers of the same tier back. For example:

```recipe
type: crafting_shapeless
ingredients: [hopperxtreme:diamond_multi_hopper]
result: hopperxtreme:diamond_hopper
count: 4
```
