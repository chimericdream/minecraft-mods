# Config sync layer

> Source: legacy backlog, [§ Cross-cutting infrastructure](../brainstorms/2026-08-27-legacy/potential-features.md#cross-cutting-infrastructure) · Status: **Exploring**

## Description

A small channel that syncs server-authoritative YACL config values to clients
on join, with a consistent "server value overrides local" indicator in config screens. Nearly every mod
in the suite with server-side config wants this.
