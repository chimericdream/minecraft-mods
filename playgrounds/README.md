_Playground equipment you can actually play on_

## Introduction

Playgrounds adds playground equipment that you can actually play on: swings that swing, slides you slide down,
seesaws that tilt, climbing frames, and the other pieces of a real playground. The mod is planned and not built
yet.

### Minecraft Versions

* 26.2: Supported

### Current Features

None yet. The mod is a placeholder while the first features are built.
