# Athenaeum — Ideas

Feature ideas for this mod, from first thought to ready to build. The process is described in
[`docs/FEATURE-WORK.md`](../../docs/FEATURE-WORK.md).

## Identity

> **Written works worth finding.** Athenaeum adds custom written books and the content around them to
> the game, giving players a reason to explore beyond normal loot. It is datapack-driven, so books and
> where they appear are easy to customize and extend. Ideas should be about the books themselves and
> how players discover them: more titles, more places to find them, metadata such as genre, and light
> supporting content like advancements.

### Boundary with the future library mod

This mod is deliberately narrow. It is included in a popular modpack, so it must keep working in
existing worlds, and its ID and content won't change in ways that break them. The grander vision
(Bibliocraft-style furniture and display blocks, a printing press with bookbinding, and the like) will
be a separate sibling mod, not a rewrite of this one.

- **This mod owns** book content, loot-table placement, book metadata, and advancements.
- **The sibling mod owns** blocks, workstations, and mechanics for displaying, making, or organizing
  books. It will use Athenaeum's books when they're installed, but must work without them.
- **Not decided:** the sibling's name, and where it ends and Minekea's furniture begins.
- Ideas for the sibling mod don't belong in this folder.
