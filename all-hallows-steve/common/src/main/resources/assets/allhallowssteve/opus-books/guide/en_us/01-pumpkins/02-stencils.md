Stencils decide what a carved side looks like. Craft a Blank Stencil first, then combine it with a matching item.

```recipe
type: crafting_shapeless
ingredients: [paper, pumpkin_seeds]
result: allhallowssteve:pumpkin_stencils/blank
```

For example, a Blank Stencil and a creeper head make the Creeper stencil.

```recipe
type: crafting_shapeless
ingredients: [allhallowssteve:pumpkin_stencils/blank, creeper_head]
result: allhallowssteve:pumpkin_stencils/creeper
```

## The collection

Blank, Crafter, Creaking, Creaking Heart, Creeper, Dispenser, Dropper, Heart, Jack o'Lantern, Jigsaw, Lodestone,
Observer, Spawner, Structure Block, and Wither Rose.

> [!NOTE] Rare stencils
> The Heart, Jigsaw, Spawner, and Structure Block stencils can't be crafted. Find them as rare loot in village
> houses, strongholds, woodland mansions, dungeons, ancient cities, and end cities.
