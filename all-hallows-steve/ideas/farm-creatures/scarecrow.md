# Scarecrow

> Shortlist #16 · Tier 2 — Solid mid-size features · Effort **M–L** · Value ★★★ · Votes 7 · My vote **Yes**

## Description

The second most-suggested idea. It's an armor-stand-like entity with a (decorated) pumpkin head that can
be dressed. Give it one clear job so it's more than decoration: **no crop trampling and no rabbits eating
crops within a radius**, and later it scares off crows (#23). Keep it stationary and without personality,
as the brainstorms warned. If entity work is too heavy, a static multiblock is a cheaper fallback.

## Brainstorm variants

From [combined-ideas § 4](../brainstorms/2026-09-29/combined-ideas.md#4-gourds-crops--farming). Bracketed numbers
are the `brainstorms/2026-09-29/agentN.md` files that suggested each variant.

- Built from sticks, hay, and a carved (decorated) pumpkin head. They can be dressed like an armor stand
  [1, 2, 5, 7, 10, 12, 13]. Suggested functions vary:
  - Scares off crows [1, 5, 13] or rabbits eating crops [10, 13].
  - Reduces crop trampling within a radius [5, 7].
  - Deters passive mobs from fields [7], or hostile ones such as zombies and phantoms [12].
  - Purely decorative and stationary [2].
  - Weathers over time and needs repair [7].
- Tone note [8]: avoid "animated scarecrows with personalities".
